# 📌 Overview

**Crypto AI Analyst** is an AI-powered Web3 application that enables users to analyze cryptocurrency portfolios, gain intelligent investment insights, and manage privacy preferences using blockchain technology.

Built during the **Team1 India SpeedRun Hackathon**, the project combines modern full-stack development, AI-powered analytics, and smart contracts on the Avalanche blockchain to deliver secure and insightful portfolio management.

---

# 🚀 Key Features

### 🤖 AI Portfolio Analysis
Generate intelligent insights about portfolio performance using AI.

### 📊 Portfolio Intelligence
View wallet assets and analyze overall portfolio allocation.

### 🔒 Privacy-First Design
User privacy preferences are managed through Solidity smart contracts.

### ⛓️ Avalanche Integration
Built on the Avalanche ecosystem for fast and low-cost transactions.

### 🌐 Modern Web Interface
Responsive and interactive dashboard built with Next.js.

### ⚡ REST API Backend
Efficient backend services using Express and TypeScript.

### 🧩 Modular Architecture
Clean separation between frontend, backend, smart contracts, and documentation.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/SoumyaPandey25/Crypto_AI_Analyst.git
```

---

## Install Dependencies

### Frontend

```bash
cd frontend

npm install

npm run dev
```

### Backend

```bash
cd backend

npm install

npm run dev
```

### Smart Contracts

```bash
cd contracts

npm install

npx hardhat compile
```
